# Interface design guidelines

- Product: Campus Walkie-Talkie Channel and Time-Slot Allocation Engine.
- Visual system: navy/charcoal navigation rail, white content surfaces, pale grey workspace and restrained blue accent.
- Avoid purple gradients, neon glows, oversized hero cards and decorative illustrations.
- Use a persistent left sidebar with separate administrator and group-user navigation.
- Use readable data tables, compact metric cards, consistent spacing and restrained status colours.
- Status colour is always accompanied by a text label.
- Timetable is a channel-row × 48-slot-column matrix; channel 16 remains visibly reserved.
- Use empty states when there is no data; never fill dashboards with fabricated metrics.
- All controls in the delivered pages should navigate to a real route or submit a real form.
